# Appendix C — Glossary

| Term | Definition |
|------|------------|
| **Annular ring** | Copper ring remaining around a drilled hole: (pad − drill)/2 |
| **Anti-pad** | Clearance opening in a plane around a via/pad not connected to that plane |
| **Anti-resonance** | Impedance peak formed when parallel capacitors (one inductive, one capacitive) resonate |
| **AOI** | Automated optical inspection |
| **Aspect ratio** | Board thickness / drill diameter |
| **BGA** | Ball grid array package |
| **Blind / buried via** | Via visible on one outer layer only / not visible on either outer layer |
| **BOM** | Bill of materials |
| **Bulk capacitor** | Large-value capacitor supplying low-frequency current |
| **Centroid / PnP file** | Component X/Y/rotation/side for the pick-and-place machine |
| **CM / DM** | Common mode / differential mode |
| **CMRR / PSRR** | Common-mode / power-supply rejection ratio |
| **Core / prepreg** | Cured laminate with copper / uncured bonding sheet |
| **Courtyard** | Keep-out area around a component, used for placement spacing |
| **Creepage / clearance** | Surface / through-air distance between conductors |
| **Crosstalk (NEXT/FEXT)** | Unwanted coupling; near-end / far-end |
| **DFM / DFA / DFT** | Design for manufacturing / assembly / test |
| **Df / Dk** | Dissipation factor (loss tangent) / dielectric constant (εr) |
| **DNP** | Do not populate |
| **DRC / ERC** | Design rule check (PCB) / electrical rule check (schematic) |
| **ECO** | Engineering change order (Altium: schematic ↔ PCB sync; industry: a controlled change) |
| **ENIG / HASL / OSP** | Surface finishes: nickel-gold / hot-air solder / organic |
| **ENOB** | Effective number of bits |
| **ESD / EFT / TVS** | Electrostatic discharge / electrical fast transient / transient voltage suppressor |
| **ESL / ESR** | Equivalent series inductance / resistance |
| **Fiducial** | Optical alignment mark for assembly machines |
| **Fly-by topology** | Daisy-chained routing with minimal stubs (DDR address bus) |
| **GCPW** | Grounded coplanar waveguide |
| **Gerber (RS-274X / X2)** | Standard photoplot format for PCB layers |
| **Guard ring** | Conductor surrounding a sensitive node, driven at the node's potential |
| **HDI** | High-density interconnect (microvias, fine lines) |
| **Hot loop** | High di/dt current loop in a switching converter |
| **IBIS** | Behavioral I/O buffer model for SI simulation |
| **Impedance profile** | Altium's stored width/gap for a target Z per layer |
| **IPC** | Standards body for electronics manufacturing (IPC-2221, -2152, -7351, -6012, -A-610) |
| **Kelvin connection** | Separate force and sense connections for accurate measurement |
| **LDO** | Low-dropout linear regulator |
| **Microstrip / stripline** | Outer-layer trace over a plane / inner trace between two planes |
| **MSL** | Moisture sensitivity level |
| **Net class / diff pair class** | Named groups of nets for rules |
| **Net tie** | Component deliberately joining two nets |
| **ODB++ / IPC-2581** | Intelligent single-file fab/assembly data formats |
| **PDN** | Power delivery network |
| **Polygon pour** | Copper fill area connected to a net |
| **Return path** | Path of current back to the source (usually through a reference plane) |
| **Room** | Altium region grouping components (per sheet/channel) |
| **SERDES** | Serializer/deserializer (multi-Gbps links) |
| **SI / PI** | Signal integrity / power integrity |
| **Skew** | Timing difference between signals |
| **SRF** | Self-resonant frequency |
| **Stencil** | Metal sheet with apertures for solder paste printing |
| **Stitching via** | Via connecting ground areas/planes together |
| **Stub** | Unused branch of a trace or via beyond the connection |
| **Teardrop** | Copper fillet at trace-pad junction |
| **Tenting** | Covering a via with solder mask |
| **Tg** | Glass transition temperature of laminate |
| **Thermal relief** | Spoked pad connection to a pour that limits heat sinking during soldering |
| **Tombstoning** | Small passive lifting on one end during reflow |
| **VIPPO** | Via-in-pad plated over |
| **xSignal** | Altium's pad-to-pad signal path spanning passive components |
| **Z0 / Z_diff** | Characteristic / differential impedance |
